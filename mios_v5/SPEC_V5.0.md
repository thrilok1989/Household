## 1. Hard rules (every engine, no exceptions)

1. **Never fabricate.** If an engine cannot compute (missing data, API failure),
   it returns **NEUTRAL** with a reason — never a fake value.
2. **Structured errors.** Every failure is a record: timestamp, engine,
   error type (`MISSING_API | MISSING_DATA | FAILED_FORMULA | TIMEOUT |
   INVALID_CALCULATION | DATA_LIMIT | STALE_DATA`), reason, severity
   (`INFO | WARNING | ERROR | CRITICAL`), data source, recovery status —
   stored in Supabase (`engine_errors`, migration 009).
3. **Data-limits are not alarms.** Engines that structurally cannot run at
   retail Dhan (L2 depth, tick tape, spoofing detection) return
   **DISABLED** and log `DATA_LIMIT` at severity **INFO** — they never light
   the Error Monitor red.
4. **Uniform contract.** Every engine returns `EngineResult`:
   bias · confidence · evidence · risks · opportunities · status ·
   provenance (source + trust **Tier 1 executed / 2 derived / 3 resting** +
   freshness) · errors · runtime. (`mios_v5/core/contract.py`)
5. **No BUY/SELL, ever.** Output is bias + confidence + evidence + risks +
   levels + invalidation. **The trader decides.**
6. **Modular.** Every engine is its own module implementing the `Engine`
   base class; the `Orchestrator` runs them in dependency (topological)
   order over a shared `MarketState`.
7. **Degrade, don't vanish.** A crashing engine yields a structured ERROR
   result; the pipeline continues. Downstream engines read upstream results
   via `state.require()` (missing upstream → honest NEUTRAL placeholder).

## 2. Architecture

```
host app (vob_minimal.py → later mios dashboard)
        │  raw inputs: spot, candles, option_data, api/db handles, flags
        ▼
  MarketState (shared blackboard)
        ▼
  Orchestrator ── topo-ordered ──► Engine 0 … Engine 41
        │                            each → EngineResult into MarketState
        ▼
  RunReport ──► Stage 0 Health score ──► Error Monitor / System Health panel
```

It is a **DAG, not a chain** — e.g. Stage 35 (Reaction Zone) consumes
Stages 7, 8, 9, 10, 11, 25, 31–34.
