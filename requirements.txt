# MIOS V6 — deployment requirements.
#
# ⚠️ Every line has an UPPER bound. Before this, every line was `>=` with no
# cap, which meant Streamlit Cloud re-resolved the whole tree on each rebuild
# and could move a dependency across a major version without anything asking.
# That is how the front end broke with:
#
#     TypeError: Failed to fetch dynamically imported module:
#     https://…streamlit.app/~/+/static/js/
#
# Streamlit serves hash-named JS chunks. A rebuild that lands on a different
# Streamlit version writes different chunk names, and a browser still holding
# the previous `index.html` asks for files that no longer exist. Pinning the
# front end is what stops a redeploy from breaking a live session.
#
# It also closes a quieter gap: the app that ships was resolved separately from
# the app the tests ran against, so "2,135 tests pass" described a dependency
# tree no deployment necessarily had.
#
# ── the convention ──
#   `==`  the front end. Its version IS the served asset, so it is exact.
#   `~=`  everything else: patch and minor updates flow in, majors do not.
#
# ── when raising a pin ──
# Raise it deliberately, run the suite, redeploy. A bound that drifts on its
# own is the thing this file exists to prevent.

# ── the front end · exact ────────────────────────────────────────────────
# 1.60.0 is the version this repo's test suite runs against. Check it against
# the Streamlit Cloud build log before assuming a redeploy is a no-op — if
# Cloud has been serving something else, this pin is a real version change and
# wants a look at the app, not just at the tests.
streamlit==1.60.0

# ── verified by the test suite ──────────────────────────────────────────
# Installed in the environment the 2,135 tests run in, at these versions.
requests~=2.33.1
pandas~=3.0.5
numpy~=2.4.6
scipy~=1.17.1
plotly~=6.9.0
pytz~=2026.3
websockets~=16.1.1

# ── NOT installed in the test environment ───────────────────────────────
# Nothing in the suite imports these, so the bounds below are the existing
# floors with a major-version cap added — they are NOT versions anything here
# has exercised. Bounded so a rebuild cannot cross a major silently; not
# claimed to be tested.
#
# `streamlit-autorefresh` sits here rather than beside `streamlit` despite
# being a front-end component: it is not installed in the test environment
# either, and the heading has to mean what it says.
